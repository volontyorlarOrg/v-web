# Security

Report suspected vulnerabilities privately to the project owner. Do not open a
public issue containing credentials, personal data, exploit details, or Telegram
integration secrets.

This repository is the public Volontyorlar marketing site. It has no
authentication, no sessions, no forms, no database, and no backend connection,
and it sets no cookies. See [`docs/security/SECURITY.md`](docs/security/SECURITY.md)
for the verified trust boundary, the response headers, and the known gaps.

Volunteer accounts and any handling of volunteer data belong to the separate Volontyorlar
application; report issues in those areas to that repository.
