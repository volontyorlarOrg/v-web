# Volontyorlar Brand Assets

## Source authority

The supplied JPEG is the visual reference for the new logo. It shows a teal,
open human figure above the lowercase word `volontyorlar`. The source is a
compressed screenshot, not a master vector, so the rebuilt assets preserve its
recognizable geometry while avoiding JPEG edges and blur.

An archived copy lives at `docs/brand/reference/volontyorlar-logo-reference.jpg`.
The original Telegram temporary path must not be treated as durable storage.
Its SHA-256 checksum is
`36902f064e74553cbdba919beef096aeec1454060c8b470b459dadc18b82d37e`.

## Working identity

| Token | Value | Use |
| --- | --- | --- |
| Volontyorlar teal | `#45C1C4` | Mark, wordmark, primary action, focus |
| Night ink | `#071719` | V3 canvas and dark icon ground |
| Soft white | `#F4FBFB` | Text and reversed logo |

The wordmark is custom monoline SVG geometry and has no font dependency. The
mark and wordmark may be recolored only as a single unit. Preserve clear space
equal to the mark's head radius and never stretch, rotate, outline, or add glow.
